# Probelet

**Probelet** is a lightweight, all-in-one API & System Simulator. It combines the features of `httpbin` with powerful hardware stress-testing capabilities.

Whether you are testing Kubernetes probes, debugging microservices latency, or validating system monitoring, Probelet gives you full control over your environment via a simple HTTP API.

---

## 🔥 Key Capabilities

- 🌐 **HTTP Swiss Army Knife**: Test any status code, headers, and payloads (like httpbin).
- ⏳ **Chaos Engineering**: Inject latency and simulate flaky dependencies.
- 🏋️ **Hardware Stress**: Trigger CPU spikes and Memory leaks on demand.
- 📦 **Zero-Config**: A single Go binary that runs anywhere (Linux, macOS, Windows, Containers).
